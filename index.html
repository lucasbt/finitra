🚀 Quick Start

Instalação em Uma Linha

A forma mais fácil de provisionar seu sistema:

curl -fsSL https://raw.githubusercontent.com/lucasbt/initora/main/bootstrap.sh | bash

Instalação Manual

Se preferir inspecionar o código antes de executar:

git clone https://github.com/lucasbt/initora ~/.local/share/initora
cd ~/.local/share/initora
bash bootstrap.sh

📚 Documentação

Comandos CLI

  • initora - Seletor interativo de módulos
  • initora install - Executar todos os 5 módulos
  • initora install -m 20 - Executar módulo específico
  • initora list - Listar módulos disponíveis
  • initora config - Editar configuração

Customização

  • Editar ~/.config/initora/initora.config
  • Adicionar pacotes RPM em data/rpm-pkgs.list
  • Adicionar Flatpaks em data/flatpak-pkgs.list
  • Criar novos módulos em modules/
